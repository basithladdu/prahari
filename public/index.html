Track 2: OS & Kernel Level Security

Secure Boot That Detects Malicious Sequence Inversion

Traditional static allowlists (Keylime, IMA) check each binary hash in isolation, completely missing BlackLotus downgrade attacks, stage inversions, and revoked kernel module substitutions. PRAHARI models execution order with dual-axis token projection and hybrid post-quantum attestation.

🧠

Dual-Axis Projection

Decouples Identity Token (path) from Content Token (hash) to distinguish updates from attacks.

🔄

Sequence N-Gram Model

Tracks valid boot lifecycle transitions, converging in just 4–5 baseline boots with zero cold-start delay.

📜

IETF RATS Evidence

Generates verifiable RFC 9334 JSON Claims containing observed stages and transition trust ratings.

🔐

Post-Quantum Hybrid

Dual-signed using OpenSSL 3.5 ML-DSA-65 (NIST FIPS 204) + RFC 9019 ECDSA P-256.
